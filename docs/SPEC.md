## 1. 数据结构

### 1.1 Rule（规则 —— 掌握度的最小单位）

```js
{
  id: 'te-mbn',
  lessonId: 'te',
  label: 'む・ぶ・ぬ → んで',
  applies: { type: 'godan', endings: ['む','ぶ','ぬ'] },
  transform: { drop: 1, add: 'んで' },
  note: '拨音便。む・ぶ・ぬ 三者变形结果相同，逆推时存在歧义。'
}
```

### 1.2 Verb（动词）

```js
{
  id: 'kaeru-return',
  kanji: '帰る',
  kana: 'かえる',
  meaning: '回去',
  type: 'godan',            // godan | ichidan | suru | kuru
  level: 'N5',
  traps: ['ru-looks-ichidan'],
  overrides: {              // 仅不规则动词需要，引擎优先读取
    // te: { kanji: '行って', kana: 'いって' }
  }
}
```

### 1.3 Lesson（知识点）

```js
{
  id: 'te',
  courseId: 'N5',
  order: 4,
  title: 'て形',
  ruleIds: ['te-ichidan','te-utsuru','te-mbn','te-ku','te-gu','te-su','te-iku','te-suru','te-kuru'],
  modes: ['study','rule','produce','reverse']
}
```

分类知识点 `classify` 的 modes 为 `['study','classify']`。

## 2. 活用引擎

### 2.1 接口

```js
conjugate(verb, form) -> {
  kanji: '読んで',
  kana:  'よんで',
  ruleId: 'te-mbn',
  chain: [ ...见 2.3 ]
}
```

`form` ∈ `dict | masu | te | ta | nai | tai`

### 2.2 推导顺序

1. 若 `verb.overrides[form]` 存在，直接返回，`ruleId` 取该动词专属规则（如 `te-iku`）。
2. 若 `verb.type === 'suru'`：切掉末尾 `する`，接 `し + 词尾`。
3. 若 `verb.type === 'kuru'`：查 `kuru` 专用表（注意假名读音变化 きます / きて / きた / こない）。
4. 若 `verb.type === 'ichidan'`：切掉末尾 `る`，接词尾。
5. 若 `verb.type === 'godan'`：取末尾假名，按下表映射。

**五段映射表**（引擎唯一需要硬编码的部分）

| 词尾 | ます形(い段) | ない形(あ段) | て形 | た形 |
|---|---|---|---|---|
| う | い | **わ** | って | った |
| つ | ち | た | って | った |
| る | り | ら | って | った |
| む | み | ま | んで | んだ |
| ぶ | び | ば | んで | んだ |
| ぬ | に | な | んで | んだ |
| く | き | か | いて | いた |
| ぐ | ぎ | が | いで | いだ |
| す | し | さ | して | した |

汉字形与假名形用同一套逻辑处理（都是「切掉末尾假名 + 接新词尾」），不需要两套代码。

たい形 = ます形词干 + たい。

### 2.3 推理链（chain）

答错时必须完整展示，答对时折叠可展开。

```js
[
  { step: '词典形', value: '読む' },
  { step: '动词类型', value: '五段动词', why: 'う段结尾，且非一段/不规则' },
  { step: '词尾', value: 'む' },
  { step: '适用规则', value: 'む・ぶ・ぬ → んで', ruleId: 'te-mbn' },
  { step: '拼接', value: '読 + んで' },
  { step: '结果', value: '読んで' }
]
```

五段动词的 `ます形 / ない形` 链条中，额外渲染**段位尺**组件（见 CLAUDE.md 设计方向）。

## 3. 训练模式

| 模式 | 题面 | 作答方式 | 限时 |
|---|---|---|---|
| study 学习 | 规则卡片 + 段位尺 + 例词 | 无 | 无 |
| classify 判定 | `読む` | 三选一：一段 / 五段 / 不規則 | 3 秒 |
| rule 规则 | `読む` → て形 | 六选一：って / んで / いて / いで / して / 直接接て | 3 秒 |
| produce 输出 | `読む` → て形 | 文本输入 | 5 秒 |
| reverse 逆推 | `読んで` | 输入词典形 + 选择形态名 | 4 秒 |

**逆推模式说明**：这是 JLPT 读解与文法题的真实题型方向。
ん 结尾存在真歧义（読んで/遊んで/死んで 分别来自 む/ぶ/ぬ），
逆推时若答案不唯一，接受任一正确原形并提示其余可能。

**输入判定**：接受汉字形或假名形；自动去除首尾空白；全角半角归一化；
不接受多余标点。答错时先判断是否属于「形对但汉字写错」，若是，单独提示，不计为规则错误。

## 4. 间隔重复（SRS）

**这是本项目对长期保持率影响最大的机制，优先级最高。**

调度单位是**规则**，不是单词。规则到期后，从该规则名下的动词池中抽题（抽题权重见 §5）。

### 4.1 状态

```js
{
  ruleId: 'te-gu',
  ease: 2.5,        // 1.3 ~ 3.0
  interval: 0,      // 天
  due: '2026-07-27',
  reps: 0,
  lapses: 0,
  history: [ { ts, correct, ms } ]   // 保留最近 20 条
}
```

### 4.2 评分（SM-2 简化版）

每次作答后按下表更新。`fast` 指用时未超过该模式限时。

| 结果 | ease | interval |
|---|---|---|
| 正确 + fast | +0.05（上限 3.0） | reps=0→1天；reps=1→3天；否则 ×ease |
| 正确 + slow | 不变 | reps=0→1天；reps=1→2天；否则 ×1.3 |
| 错误 | −0.20（下限 1.3） | 重置为 0（本次会话内重新出现），lapses+1 |

`due = today + interval`。间隔上限 60 天（考前不必更长）。

### 4.3 会话组题

一次训练 20 题，按此比例取：

- 60% 到期复习（due ≤ today，按 due 升序）
- 25% 薄弱规则（就绪度最低的 3 条规则）
- 15% 新规则或未练习规则

若到期项不足，用薄弱规则补足。

## 5. 陷阱词加权

JLPT 动词题高度集中在固定歧义点。抽题时陷阱词权重 = 普通词 × 3.5。

| trap 标记 | 内容 | 说明 |
|---|---|---|
| `ru-looks-ichidan` | 帰る・入る・走る・切る・知る・要る・減る・滑る・散る・limit 参る | 形似一段的五段，最高频考点 |
| `n-ambiguous` | 読む/遊ぶ/死ぬ 及同类 | 逆推唯一真歧义点 |
| `iku-special` | 行く → 行って | 必考特殊变形 |
| `ku-gu-voicing` | 書く/泳ぐ 对照 | いて / いで 浊化粗心点 |
| `homophone-pair` | 着る(一段) / 着く(五段) / 切る(五段) | 直接考分类判断 |
| `suru-compound` | 勉強する・散歩する・電話する | N4 起高频 |

同一规则内连续出题时，不得连续两题使用同一动词。

## 6. 就绪度（取代裸准确率）

界面显示文案：**「若今天考试，此规则预计正确率 X%」**

```
readiness = accuracy × retention × automaticity
```

- **accuracy**：最近 10 次作答的加权准确率，第 i 近的权重为 `1/(i+1)`。无记录时为 null（显示「未练习」）。
- **retention**：`exp(-daysSinceLastCorrect / max(interval, 1))`。下限 0.3。
- **automaticity**：最近 10 次「正确且未超时」占「正确」的比例。不足 3 次记录时取 0.8。

知识点就绪度 = 其名下所有规则就绪度的**最小值**，不是平均值。
理由：考场上短板决定成绩，平均值会掩盖 40% 的 `ぐ→いで`。

课程就绪度同理取各知识点最小值。

**显示分档**：≥85% 绿（已自动化）／60~84% 琥珀（会但不够快）／<60% 朱红（需强化）／无记录灰。

## 7. Phase 划分

| Phase | 范围 | 验收标准 |
|---|---|---|
| 1 | N5 分类 / ます形 / て形；五种模式；SRS；就绪度；localStorage | 我能每天用它练 15 分钟，て形六条规则就绪度全部 ≥85% |
| 2 | N5 补 ない形 / た形 / たい形；错题本；段位尺动画 | N5 全部知识点就绪度 ≥85% |
| 3 | N4 可能/意志/命令/禁止/条件；N3 被动/使役/使役被动/敬语 | 数据驱动扩展，引擎不改 |
| 4 | Spring Boot 后端；用户系统；跨设备同步；数据导出 | 毕设与软著材料 |

Phase 1 未完成前不得开始 Phase 2。
