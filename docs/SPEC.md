# Japanese Verb Trainer — 规格与架构

个人 JLPT 备考工具。目标：看到一个动词，能立即完成「属于什么类型 → 该套哪条规则 →
为什么这样变 → 写出正确活用」。不是词汇书，不是刷题网站，不是 AI 聊天。

约束见根目录 `CLAUDE.md`（优先级高于本文件）。

## 一、学习闭环

```
学习（讲规则） → 规则应用（专项练习） → 输出（完整变形） → 综合训练 → 错题强化
```

关键点：学完「む・ぶ・ぬ→んで」后，专项练习直接问「読む→？」，
中间不插入「这是什么类型动词」的判断步骤。分类能力是独立技能，单独练、单独统计。

## 四、架构

### 静态内容 vs 动态数据

规则表和动词库是 `src/data/*.ts` 里的 TypeScript 常量，不入库。理由：
有类型检查、能跑单测、进 git 版本管理，且省掉一套永远可能和代码漂移的 seed 流程。

数据库只存三张表：

- `attempts` — 每次作答的流水，掌握度的唯一事实来源，只追加不删。
- `rule_mastery` — 按 `rule_id` 聚合的掌握度，可从 attempts 完整重算。
- `generated_content` — LLM 生成内容缓存。

`ruleId` / `verbId` 是指向 TS 常量的字符串，不做数据库外键，完整性由 TypeScript 保证。

对 N4/N3 扩展的影响：`rule_mastery` 以字符串 `rule_id` 为主键，将来加可能形、被动形
只是往 `src/data/rules.ts` 加常量 + 课程表加一课，**不需要任何 schema 变更或迁移**。

### 内容生成

`getContent(kind, cacheKey)`：查 `generated_content` → 命中即返回 → 未命中才调 Anthropic API
→ zod 校验结构 → 写库 → 返回。缓存键含 `promptVersion` 与 `model`。

另配预生成脚本，可一次性把 N5 全部规则讲解灌进库，正式使用时不会卡在等 LLM 生成。

**大模型不产出活用答案**，只产出讲解文案。见 `CLAUDE.md` 铁律 1。

### 访问方式

站点直接访问，不提供账号、密码、Cookie 会话或登录拦截。

## 五、本地开发

```bash
npm install
cp .env.example .env.local     # 然后填 DATABASE_URL
npm run db:migrate             # 建表
npm run dev
```

改了 `src/db/schema.ts` 之后：`npm run db:generate` 生成迁移 SQL，`npm run db:migrate` 应用。
